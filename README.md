# ![Sensible Storage](img/sensible_storage_logo.gif)

## Features

### Real Wooden Chests!

If you've ever thought the default chest looked kinda plain, this is the mod for you.
Make a chest with all of the same wood type and you get a chest that actually looks like that wood!

![chest recipes](img/planked_chests_vanilla_sequence/recipes.gif)


### More chest minecarts! (now with animated lid)

All storage blocks now have minecart variants:
- The chest lid opens and closes like it always should have.
- Copper chests weather and can be waxed, too.
- Trapped chests are 100% functional.
- Shulker boxes can be put into minecarts and keep their contents.
- You can put a barrel in a minecart now, for some reason.

[storage minecarts demonstration](img/storage_minecarts_demonsration.gif]


### Mod support!

Supports Cinderscapes, Enderscape, Terrestria, Traverse, and Woods and Mires.
Let me know if you'd like to see any other modded wood types added!


## Install

Download the .jar from [the releases page](releases/latest) and drop it into your mods folder.
Fabric only; requires [Polymer](https://github.com/patbox/polymer).

Installing as a client mod gets rid of the visual jank which is an unavoidable limitation of how Polymer works.
