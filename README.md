## Features

### Real Wooden Chests!
![vanilla wood chests showcase](img/showcase_vanilla_single.png)

If you've ever thought the default chest looked kinda plain, this is the mod for you.
Make a chest with all of the same wood type and you get a chest that actually looks like that wood!

![chest recipes](img/planked_chests_vanilla_sequence/recipes.gif)

### Mod support!

Supports Cinderscapes, Enderscape, Terrestria, and Woods and Mires.
Let me know if you'd like to see any other modded wood types added!

### Vanilla chests are disabled by default.
Bring it back with `/datapack disable plankedchests:disable_vanilla_recipes`

## Install

### Server

Download the .jar from [the releases page](releases/latest) or [Modrinth](https://modrinth.com/mod/planked-chsts)  and drop it into your mods folder.
Fabric only; requires [Polymer](https://modrinth.com/mod/polymer). Vanilla clients see the chests
via Polymer's server resource pack — no client mod needed.

### Client (optional)

Install the **same jar** plus [Polymer](https://modrinth.com/mod/polymer) on your client gets rid of the
full-block outlines and ghost block placement if you open the chest while holding a block.
Without it, everything still works, but the visual jank is an unavoidable limitation of how Polymer works.
